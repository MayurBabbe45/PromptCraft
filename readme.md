# Prompt Refiner Chrome Extension

Prompt Refiner is a lightweight Chrome extension that helps you generate better AI prompts instantly.  
It takes a simple idea and refines it into a structured prompt so you can get more accurate and useful responses from AI tools like Gemini.

---

## Features

- Refines simple prompts into structured prompts
- Works directly from your Chrome browser
- Uses Gemini API for prompt enhancement
- Simple and minimal interface
- Easy setup (less than 1 minute)

---

## Installation Guide

Follow these steps to install the extension manually:

1. Download the `prompt-refiner.zip` file.
2. Extract (unzip) the file to a folder on your computer.
3. Open Google Chrome.
4. In the address bar, go to:

   chrome://extensions

5. Enable **Developer Mode** using the toggle in the top right corner.
6. Click **Load unpacked**.
7. Select the **unzipped prompt-refiner folder**.

The extension will now appear in your Chrome extensions list.

---

## Setup

1. Click the **✦ Prompt Refiner extension icon** in your browser toolbar.
2. Paste your **Gemini API Key**.
3. Click **Save**.

Your extension is now ready to use.

---

## How to Use

1. Click the Prompt Refiner extension icon.
2. Enter a basic prompt or idea.
3. The extension refines it into a structured prompt.
4. Copy the refined prompt and use it in your AI tool.

---

## Requirements

- Google Chrome browser
- Gemini API Key

You can generate a Gemini API key from Google AI Studio.

---

## Example

Input prompt:

Write a blog post about AI.

Refined prompt:

Act as an experienced technology writer. Write a detailed blog post about how artificial intelligence is transforming modern businesses. Use a professional tone and include practical examples.
